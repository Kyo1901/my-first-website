== Projects 탭 UI/UX 기획서 ==

선택한 레이아웃 방식
- 리스트 형태 레이아웃 (가로 긴 카드)

썸네일 카드 구성
이미지:
- 타입: 스크린샷
- 비율: 16:9
- 크기: 가로 800px

정보 표시:
- 프로젝트 이름 (제목)
- 한 줄 설명:
- 기술 스택: 아이콘 + 텍스트
- 기타 정보: 링크 및 버튼

링크 및 버튼:
- Live Demo 버튼
- GitHub 버튼

인터랙션 효과
- 호버 효과: 카드 테두리 + 그림자 설정
- 클릭 피드백: 버튼 애니메이션
- 모바일 터치: 터치 피드백, 스와이프 지원

반응형 설계
- 데스크톱: 1열 그리드
- 태블릿: 1열 그리드
- 모바일: 1열 그리드
- 특별 고려사항:
    - 모바일에서는 썸네일 상단, 프로젝트 정보를 하단에 배치
       = 세로로된 카드 형식

  * sort_order: (표시 순서)
  * created_at: (생성일시)
