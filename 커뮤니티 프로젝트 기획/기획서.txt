== 나만의 커뮤니티 기획서 ==

커뮤니티 주제
- 어떤 주제의 커뮤니티인가요?
  주제별 자유 토론 커뮤니티 (Reddit처럼 누구나 원하는 주제의
  게시판을 만들고 참여할 수 있는 종합 커뮤니티)
- 주요 카테고리: 일상, 기술/IT, 게임, 스포츠, 음식, 영화/드라마

디자인 스타일
- 사이트 이름: "Roundit" (둥글다 + Reddit 느낌)
- 색상 테마: 메인 민트 + 화이트 + 연한 회색 배경
- 분위기: 깔끔하고 정보 중심적인, 텍스트 가독성 우선

특별한 기능 아이디어
- 기본 기능 외에 추가하고 싶은 것들:
  · 업보트 / 다운보트 (추천 점수로 게시물 정렬)
  · 주제별 독립 게시판 (서브레딧 구조, 예: r/게임, r/맛집)
  · 게시물 저장(북마크) 기능
  · 핫 / 새글 / 탑 정렬 탭 전환
  · 플레어(태그) — 게시물에 카테고리 라벨 부착
  · 다크모드 / 라이트모드 전환

페이지별 특징
- 로그인 페이지:
  이메일+비밀번호 로그인, 소셜 로그인(구글),
  가입 시 관심 게시판 3개 선택하는 온보딩 단계 포함

- 게시물 목록:
  왼쪽 사이드바(인기 게시판 목록) + 중앙 피드(카드형 게시물) + 
  오른쪽 사이드바(커뮤니티 소개/규칙),
  상단에 핫🔥 / 새글🆕 / 탑⬆ 정렬 탭

- 게시물 상세:
  제목 + 본문(마크다운 지원) + 이미지/링크 첨부 가능,
  업보트 수 · 댓글 수 · 공유 · 저장 버튼 표시,
  작성자 프로필(카르마 점수) 표시

- 댓글 기능:
  트리형 대댓글 구조(들여쓰기로 depth 표현),
  댓글에도 업보트/다운보트,
  베스트 댓글 상단 고정

참고 사이트
- reddit.com — 전체 구조 및 투표 시스템 참고
- old.reddit.com — 심플한 텍스트 중심 레이아웃 참고
- lemmy.world — 오픈소스 Reddit 클론, 기능 구현 참고

== 커뮤니티 사이트 DB 구조 정리 ==

사용자 정보 (users 테이블)
- 회원가입/프로필 화면에서 필요한 정보들:
  * 사용자 번호:     id          (자동으로 1, 2, 3... 증가)
  * 닉네임:         username    (커뮤니티에서 표시될 이름)
  * 이메일:         email       (로그인할 때 사용)
  * 비밀번호:       password    (암호화해서 저장)
  * 프로필 사진:    profile_img (이미지 파일 경로)
  * 카르마 점수:    karma       (받은 업보트 누적 점수)
  * 화면 테마:      theme       (라이트/다크 모드 설정값)
  * 가입일:         created_at  (언제 가입했는지)

게시판 정보 (boards 테이블)
- 서브레딧처럼 주제별 독립 게시판:
  * 게시판 번호:    id          (자동으로 1, 2, 3... 증가)
  * 게시판 이름:    name        (예: 게임, 맛집, 스포츠)
  * 설명:          description (게시판 소개글)
  * 아이콘 이미지:  icon_img    (게시판 대표 이미지)
  * 개설자:        created_by  (누가 만들었는지 - users 테이블과 연결)
  * 구독자 수:      member_cnt  (현재 구독 중인 사람 수)
  * 개설일:        created_at  (언제 만들어졌는지)

게시물 정보 (posts 테이블)
- 게시물 목록/상세 화면에서 필요한 정보들:
  * 게시물 번호:    id          (자동으로 1, 2, 3... 증가)
  * 제목:          title
  * 내용:          content     (마크다운 형식 텍스트)
  * 게시물 유형:    post_type   (텍스트 / 이미지 / 링크 구분)
  * 이미지 주소:    image_url   (이미지 첨부 시 파일 경로)
  * 링크 주소:      link_url    (링크 첨부 시 URL)
  * 플레어(태그):   flair       (예: 질문, 정보, 유머 등 라벨)
  * 작성자:        author_id   (어떤 사용자가 썼는지 - users 테이블과 연결)
  * 게시판:        board_id    (어느 게시판에 올렸는지 - boards 테이블과 연결)
  * 투표 점수:      vote_score  (업보트 수 - 다운보트 수)
  * 댓글 수:       comment_cnt (댓글이 몇 개 달렸는지)
  * 작성일:        created_at  (언제 썼는지)
  * 수정일:        updated_at  (마지막으로 언제 수정했는지)

댓글 정보 (comments 테이블)
- 댓글/대댓글 화면에서 필요한 정보들:
  * 댓글 번호:      id          (자동으로 1, 2, 3... 증가)
  * 댓글 내용:      content
  * 작성자:        author_id   (어떤 사용자가 썼는지 - users 테이블과 연결)
  * 게시물:        post_id     (어떤 게시물의 댓글인지 - posts 테이블과 연결)
  * 부모 댓글:      parent_id   (대댓글이면 원댓글 번호, 일반 댓글이면 비워둠)
  * 투표 점수:      vote_score  (댓글 업보트 수 - 다운보트 수)
  * 작성일:        created_at  (언제 썼는지)
  * 수정일:        updated_at  (마지막으로 언제 수정했는지)

투표 정보 (votes 테이블)
- 업보트/다운보트 기록:
  * 투표 번호:      id          (자동으로 1, 2, 3... 증가)
  * 투표한 사람:    user_id     (누가 투표했는지 - users 테이블과 연결)
  * 대상 유형:      target_type (게시물 투표인지 / 댓글 투표인지 구분)
  * 대상 번호:      target_id   (어떤 게시물/댓글에 투표했는지)
  * 투표 종류:      vote_type   (업보트 / 다운보트)
  * 투표일:        created_at

북마크 정보 (bookmarks 테이블)
- 게시물 저장 기능:
  * 북마크 번호:    id          (자동으로 1, 2, 3... 증가)
  * 저장한 사람:    user_id     (누가 저장했는지 - users 테이블과 연결)
  * 저장한 게시물:  post_id     (어떤 게시물인지 - posts 테이블과 연결)
  * 저장일:        created_at

게시판 구독 정보 (board_members 테이블)
- 게시판 구독/참여 기록:
  * 번호:          id          (자동으로 1, 2, 3... 증가)
  * 구독한 사람:    user_id     (누가 구독하는지 - users 테이블과 연결)
  * 구독한 게시판:  board_id    (어떤 게시판인지 - boards 테이블과 연결)
  * 구독일:        joined_at

테이블 연결 관계
- 사용자 → 게시판:   한 사용자가 여러 게시판 개설 가능
- 사용자 → 게시물:   한 사용자가 여러 게시물 작성 가능
- 사용자 → 댓글:    한 사용자가 여러 댓글 작성 가능
- 사용자 → 투표:    한 사용자가 여러 게시물/댓글에 투표 가능
- 사용자 → 북마크:   한 사용자가 여러 게시물 저장 가능
- 사용자 → 구독:    한 사용자가 여러 게시판 구독 가능
- 게시판 → 게시물:   한 게시판에 여러 게시물 존재
- 게시물 → 댓글:    한 게시물에 여러 댓글 작성 가능
- 댓글  → 댓글:    한 댓글에 여러 대댓글 작성 가능 (parent_id로 연결)
